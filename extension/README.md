# DraftFlow Web Companion (Chrome Extension)

Официальное браузерное расширение для Google Chrome для быстрого сбора заметок, клиппинга статей, ссылок, цитат и мгновенного доступа к базе знаний DraftFlow.

---

## 🚀 Быстрый запуск в режиме разработки

1. Убедитесь, что установлены зависимости:
   ```bash
   cd extension
   npm install
   ```

2. Запустите dev-сервер WXT:
   ```bash
   npm run dev
   ```
   *WXT автоматически откроет тестовый инстанс Chrome с установленным расширением и горячей перезагрузкой (HMR).*

---

## 📦 Сборка и установка в рабочий Chrome

1. Соберите проект:
   ```bash
   cd extension
   npm run build
   ```
   Собранное расширение появится в папке `dist/chrome-mv3`.

2. Откройте в Google Chrome страницу расширений:
   ```
   chrome://extensions/
   ```
3. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку:
   ```
   /Users/toni/GitHub/draftflow/extension/dist/chrome-mv3
   ```

---

## ⚙️ Настройка подключения

1. Кликните правой кнопкой мыши по иконке расширения в Chrome и выберите **«Параметры»** (Options).
2. Введите ваш **Supabase Project URL** и **Anon Key**.
3. Введите Email и пароль от вашей учетной записи DraftFlow и нажмите **«Проверить соединение и войти»**.
4. Нажмите **«Сохранить настройки»**.

---

## ⌨️ Горячие клавиши

- `Alt + Shift + D` (Mac: `Option + Shift + D`): Открыть всплывающее окно клиппера (Popup)
- `Alt + Shift + S`: Открыть боковую панель DraftFlow (Side Panel)
